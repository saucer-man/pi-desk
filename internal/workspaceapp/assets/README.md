# Workspace application icon assets

The Node.js application uses these bundled icons for detected workspace applications. Git Bash uses the icon from its installed executable. Product names and logos remain trademarks of their respective owners; inclusion here is solely to identify the application selected by the user and does not imply endorsement.

| `cursor.ico` | Cursor official website: <https://www.cursor.com/favicon.ico> | Cursor product icon; rights retained by Anysphere. Used only for nominative product identification. |
| `file-manager-windows.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork; project licence applies. It is not copied from Windows Explorer. |
| `file-manager-darwin.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork inspired by platform colour conventions; project licence applies. It is not copied from Finder. |
| `file-manager-linux.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork inspired by common Linux desktop colours; project licence applies. |

The original Go icon generator is retained in the legacy code archive under `bak/`. It is not needed to build or run the Node.js application.
