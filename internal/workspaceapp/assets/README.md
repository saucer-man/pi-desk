# Workspace application icon assets

These files are only fallbacks when Pi Desk cannot read the icon from an installed application. Runtime extraction remains the first choice. Product names and logos remain trademarks of their respective owners; inclusion here is solely to identify the application selected by the user and does not imply endorsement.

| --- | --- | --- |
| `vscode.ico` | Microsoft Visual Studio Code official website: <https://code.visualstudio.com/assets/favicon.ico> | Microsoft product icon. Use must follow the [Microsoft Trademark and Brand Guidelines](https://www.microsoft.com/legal/intellectualproperty/trademarks). |
| `cursor.ico` | Cursor official website: <https://www.cursor.com/favicon.ico> | Cursor product icon; rights retained by Anysphere. Used only for nominative product identification. |
| `pycharm.png` | JetBrains official brand resources: <https://resources.jetbrains.com/storage/products/company/brand/logos/PyCharm_icon.png> | Use must follow the [JetBrains Brand Guidelines](https://www.jetbrains.com/company/brand/). |
| `file-manager-windows.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork; project licence applies. It is not copied from Windows Explorer. |
| `file-manager-darwin.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork inspired by platform colour conventions; project licence applies. It is not copied from Finder. |
| `file-manager-linux.png` | Generated by `generate_icons.go` | Original Pi Desk fallback artwork inspired by common Linux desktop colours; project licence applies. |

`generate_icons.go` has the `ignore` build tag and is not part of the application binary. Run it from this directory when the platform fallback artwork needs to be regenerated.
