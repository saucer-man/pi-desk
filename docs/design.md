# Pi Desk Web 设计规范

开发进度与验收状态见 [开发计划](../REFACTOR_PLAN.md)，运行和升级说明见 [README](../README.md)。旧 Wails 设计文档已归档到 `bak/cleanup-20261105-165446/docs/`。

以 2026-11-03 用户最新要求为准，前端完整改用 DeepSeek Harness 的页面结构、字体和组件风格，替代此前 Nova 方案。参考源码位于 `D:/dsh`，本机参考服务为 `http://127.0.0.1:3080/`。

## 框架与依赖

| 用途 | 当前方案 | 依据 |
| --- | --- | --- |
| 页面 | React / React DOM 18.3.1、TypeScript 6.0.3、Vite 6.4.5、React 插件 4.7.0 | DSH `apps/web/package.json` 与已安装版本 |
| 样式、组件 | CSS Modules，仓库内原生 React 组件 | DSH `ui-theme`、`ui-primitives`；不引入其服务端插件运行时 |
| 编辑器 | Lexical 0.49.0、plain-text、history | DSH 输入框依赖；保留纯文本、换行、撤销和中文组合输入保护 |
| 图标 | DSH SVG 图形，仅保留实际使用的图标 | `packages/client/ui-primitives/src/icons/artwork.ts` |
| 状态、布局、拖放 | React `useSyncExternalStore`、原生 CSS / Pointer Events / HTML 拖放 | 保留功能，不再引入 Zustand、面板或拖拽依赖 |
| 文本、代码、PDF | markdown-it、Pi 已有的 highlight.js 10.7.3、浏览器原生 PDF | 共用一份高亮依赖；代码按需加载，PDF 使用临时 Blob；移除前端 xterm 依赖 |

DSH 本机 Vite 为 6.4.3；本项目采用同一 6.4 分支的安全修订版 [6.4.5](https://github.com/vitejs/vite/releases/tag/v6.4.5)，既有 Markdown 解析器同步修订为 [markdown-it 15.0.3](https://github.com/markdown-it/markdown-it/releases/tag/15.0.3)。

移除 Tailwind、shadcn / Base UI、Lucide、Motion、react-resizable-panels、dnd-kit、Zustand 和 Geist。全应用只保留一套组件和主题。Vite 同时是 Node 开发服务的直接开发依赖，版本与前端一致，安装时复用同一份。

## 字体与视觉

正文使用 DSH 原始系统字体栈：

```css
-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC',
'Hiragino Sans GB', 'Microsoft YaHei', 'Helvetica Neue', Helvetica, Arial, sans-serif
```

代码使用 `SF Mono`、`JetBrains Mono`、`Fira Code`、Consolas、`Liberation Mono`、Menlo、Courier 和中文系统字体；不追加可能导致 Windows 中文回退宋体的裸 `monospace`。Montserrat 仅用于品牌标识，字体文件随应用本地提供。字号与自定义字体可在设置中调整。

“Pi Desk 默认”使用上述 DSH 字体栈；“系统字体”选项以 system-ui 开头，属于单独的浏览器偏好，会覆盖默认值。需要恢复 DSH 字体时，在“外观 → 字体”选择“Pi Desk 默认”，当前页面立即生效并保存在浏览器本地，无需重启服务。

直接复用 DSH `base.css`、`design-platform.css`、`gradient-shadow-text.css`、滚动条与焦点样式。页面引用其语义 token；深色通过 `body[data-ds-dark-theme]` 切换，避免静态浅色气泡。仅状态变化使用 CSS 动画，并遵循 reduced-motion。

## 页面结构

- 浅灰侧栏、白色主区域；页面顶部无背景留白，三列采用直角分区，左右分隔线从页面顶端贯穿到底。会话标题与标签归入中央列，右侧文档栏直接从顶端开始。
- 桌面左栏默认 260 px，可在 200–440 px 内拖动；右栏默认 440 px，最小 280 px，最大值按剩余空间动态计算，中央至少保留 320 px。两侧共用原生 Pointer Events 分隔条，支持方向键、Home / End、拖动取消和宽度记忆；视口变窄时只限制显示宽度，保留原偏好。小屏继续使用导航抽屉和文档弹窗，不显示列宽手柄。
- 左上角操作仅保留新建任务、定时任务，两项共用左对齐、图标加文字的无边框导航行，统一字号、间距和悬停样式；定时任务尚未迁移，入口禁用并说明原因。工作区标题右侧依次为搜索、视图选项、添加工作区，复用现有 DSH 图标按钮。搜索沿用原会话筛选与聚焦行为，关闭后清空条件；Ctrl / ⌘ + K 在侧栏收起时先展开侧栏再聚焦搜索。下方共用一个滚动区：有置顶会话时，在工作区上方显示独立“置顶”区；置顶会话不在普通列表重复显示。“置顶”和“工作区”标题各自作为原生按钮，支持鼠标、Enter / Space 折叠展开，箭头与 `aria-expanded` 同步；两区状态互不影响，搜索 / 视图 / 添加按钮不触发折叠。没有置顶时隐藏置顶区，折叠状态在当前页面内保留。工作区目录整行为同一个折叠按钮，名称、图标和空白区域均可点击；`aria-expanded` 与文件夹图标同步，Enter / Space 可操作，不切换当前会话或清空草稿。按工作区显示时按目录折叠，单列表保持平铺；折叠状态在当前页面内保留。底栏左侧直接打开设置，右侧显示根目录 `package.json` 的版本号。视图按钮与搜索 / 添加按钮统一使用正常前景色，避免继承工作区标题的灰色而呈现不可用的观感。菜单分组仅保留按工作区 / 单列表；删除树形分组和排序功能，置顶区与普通列表各按最近更新排列。保留隐藏已归档 / 全部对话（显示已归档）/ 仅显示已归档三种筛选，并沿用原浏览器偏好保存选择；无效值默认隐藏已归档。筛选同时作用于置顶区和工作区，可与搜索、两种分组及各区折叠组合使用。旧树形偏好回退为按工作区，旧手动排序偏好不再读取；移除会话拖放排序与快捷键。
- 正文顶部使用两行标题与“对话 / 轨迹”标签。切换标签保留编辑器，左右方向键与 Home / End 可切换标签。右上角仅保留 DSH 分体“打开方式”和右侧面板按钮。移除标签旁的更多菜单、原生历史树和会话操作弹窗，以及专用的历史树查询 / 导航、手动压缩、HTML 导出接口和旧输入重试分支；侧栏菜单、消息操作、编辑框模型 / 推理等级和待发送队列继续使用原入口，Pi 原生历史格式与 SDK 自动压缩不变。
- “打开方式”左侧使用默认应用打开当前会话工作目录，无活动会话时打开工作区；下拉只显示已检测到安装文件的文件管理器、Cursor、VS Code、Windows Git Bash 与 PowerShell。PowerShell 优先检测 7.x，再回退系统 Windows PowerShell；使用独立交互窗口并继承会话目录。选择后显示启动状态并记住默认值，启动错误显示在页面；回到浏览器时刷新可用应用，失效默认值回退到可用条目。图标复用旧版应用资源、本机 Git 图标和现有终端符号。工作区入口只传工作区 / 会话 / 应用 ID，服务端校验工作区后使用固定可执行路径和独立 argv，不接受任意命令。交互应用不隐藏窗口，启动环境清除 Electron Node 模式、Node 启动选项与编辑器 CLI 旧 IPC。Windows Explorer 沿用 DSH 的文件 URI 交接方式，编码空格、逗号和等号并保留中文，使用可见的 execFile 启动，等待交接完成，超时为 10 秒；正常交接退出码 1 视为成功。其他应用检查创建进程错误及首秒内异常退出。成功提示只表示启动请求已派发，不声称窗口已呈现。
- 右侧仅保留文件管理与预览，参照本机 DSH 的文件页与文档页：固定“文件”标签、可关闭的预览标签、目录入口、最大化 / 还原及收起。目录在原列表中展开，文件列表与预览分别保留状态；活动标签自动滚入可见范围，目录入口始终可用。第二行显示完整路径的省略文本、类型、刷新和 Markdown 预览 / 源码菜单。目录缩进 18 px，文件标签为 13 px / 28 px 高，复用已有主题与图标；小屏使用现有模态面板。移除右侧变更、终端、上下文、独立浏览器界面及无调用的前端逻辑，同时移除两项 xterm 依赖。
- 对话正文最大宽度 800 px；用户气泡靠右，助手正文靠左。用户消息与每轮最终回复底部以纯图标提供复制、编辑、删除、从上下文中排除、fork，以及完整日期时间；用户日期和操作位于气泡下方，两类消息的日期均紧随 fork，间距统一为 4 px。fork 与日期成组，小屏需要换行时作为整体移动。按钮复用 IconButton，以原生 title 提供悬停说明、aria-label 提供读屏名称，复制成功时图标变为勾选并提示“已复制”。小屏按钮为 44 px；运行中禁用修改和分支，工具结果与仍在输出的助手回复不显示此操作栏。消息修改沿用 Pi context_edit，编辑保留图片 / 非文本内容，不自动重新执行，删除保留原始历史；受保护的系统与工具条目不可修改。系统消息仅进入轨迹。
- read / bash 等工具进行时展开路径、完整命令和参数，完成后调用及结果默认折叠；调用、结果与推理标题使用相同行高并垂直居中，图标 / 工具名 / 状态 / 箭头不收缩。命令及路径摘要始终单行省略，展开后在正文查看完整参数和输出；工具结果也包含对应调用参数，不依赖摘要展示完整命令。推理按 thinking_start / delta / end 同步展开与折叠，无需等待整轮结束。历史内容默认折叠，手动展开可查看参数和结果，长内容在工具区滚动。最终回复底部按成功的 edit / write 调用合并同路径的文件，展示编辑 / 写入次数及 SDK 记录的差异；整文件写入没有前值时明确说明。此汇总不推测 bash 或外部程序的文件副作用。
- 编辑与排除使用 Pi 原生 `context_edit`，后续模型请求采用新上下文。排除仍保留页面显示和标记；删除同时隐藏回复，原始记录保留在追加式历史中。fork 使用所选回复的原生 entryId，而非当前会话末尾。运行期间禁用历史修改。
- 底部编辑框最大宽度 832 px、圆角 28 px，包含加号菜单、权限说明、模型和发送按钮。支持图片粘贴 / 拖放、草稿恢复、运行中队列与停止；不显示任务费用。
- 轨迹采用 DSH 的列表与局部详情分栏交互，移除时长 / 轮次 / 调用 / 子调用开关及时间线绘图、泳道和相关状态，默认展示全部已有记录，保留全文搜索与每次 200 行的分页。轮次、类型、摘要和实际耗时使用同一行网格居中。按 toolCallId 合并调用与结果，单行摘要省略长命令，点击行查看完整参数与输出。原生消息、当前系统提示词、压缩 / 重试 / 错误及子任务事件均保留真实来源边界；当前提示词不标成初始请求快照。
- 轨迹详情复用已有 ResizeHandle 与 Dialog：工作区可用宽度足够时在右侧显示可调宽面板，否则使用弹窗。提供概述、内容、原始记录三个视图，支持键盘切换、Escape 关闭与焦点返回，切换会话或搜索时清理旧选择。仅展示 SDK / 事件已有的状态、时间、耗时、模型、Token、文件路径和 ID；工具的关联模型用量明确标注归属。支持原生推理、图片与 edit diff；结构化系统记录显示真实数据，原始记录省略图片编码。缺少时间 / 结果时不填 0 或假定仍在执行，也不构造 Pi 未记录的完整请求快照及来源标签。
- 设置使用 800 × 800 px 的弹窗和 188 px 分类侧栏，内容独立滚动；保留模型认证、资源管理和 Agent 设置。
- 小屏改为导航抽屉与全屏设置，工具面板改为弹窗。320–768 px 不产生横向溢出；保留键盘焦点限制和 Escape 关闭行为。

Pi SDK、会话、子 agent 和 `~/.pi` 数据结构沿用现有实现。定时任务入口已接入后台调度，支持真实状态和会话跳转。

默认文字规格同时对照本机 DSH 的运行页面和源码：正文 / 编辑器为 14 px、400、24 px 行高；侧栏会话标题为 14 px、400；顶部标题为 14 px、500，页面标签为 13 px、500，编辑框菜单为 13 px、500。用户 / 助手日期分别为 13 / 12 px。轨迹正文为 12 px、400、18 px 行高，类型为 10 px、650，轮次沿用 8 px 代码字体并保持网格居中，详情标签为 13 px、400。已一致的正文、编辑器、设置标签和统计样式保留；继续使用已有 ui-font-scale 响应用户的整体字号设置。

## 下拉选择控件

全应用选择控件共用 `ui.tsx` 的 `Select`，复用现有 DSH 菜单、图标、主题 token 和焦点层；不渲染系统原生下拉菜单。浮层采用圆角、柔和阴影、悬停高亮和选中勾号，跟随明暗主题；长列表限制高度并滚动，长文件名换行，按视口空间向上或向下展开。

触发器与选项使用 combobox / listbox / option 语义，保留外部 label、禁用状态、方向键、Home / End、Enter / Space、Escape、Tab / Shift+Tab 和字符定位。点击当前选项只关闭菜单，不重复触发回调，以保留资源编辑草稿。外部滚动使锚点移动时关闭浮层，恢复焦点时不改变滚动位置；忽略打开时已排队的自动滚动事件。

编辑框模型入口复用 `Menu` 的嵌套菜单：一级仅显示“模型”和“推理等级”，右侧显示当前值及箭头；点击后在同一位置进入二级列表，分别展示可用模型或 SDK 支持的等级，选中项带勾号。“模型设置”保留在模型子菜单中。运行中禁用切换；重复选择当前值不重复保存。

二级列表沿用原入口定位，根据视口空间向上或向下展开，并提供返回上级入口；长名称换行，长列表滚动。共享菜单根据浮层归属处理外部点击，保证选中后二级与一级一起关闭。方向键、Home / End、Escape 逐级返回、Tab 离开与选择后焦点恢复沿用现有交互；打开设置弹窗时焦点留在弹窗。未新增依赖或存储格式。

## 工具与推理的展开状态

复用原生 details，SDK 步骤活跃时自动展开，结束后默认折叠，用户始终可以手动开合。同一步后续增量不会覆盖手动选择，下一步和历史块的开合互不影响；箭头随实际展开状态变化。工具结果默认收起，保留命令 / 路径摘要和完成 / 失败标识。

每轮以用户输入为边界，将工具、推理和中间助手说明放入同一个执行过程。运行中默认展开，整轮完成或停止后自动收起，最终正文与本轮修改文件汇总留在过程之外；最终回复自带的推理也移入过程，不重复显示。点击状态行展开 / 收起，刷新后完成历史默认收起；没有工具或推理的普通回复不显示空的展开入口。过程内取消完整回复的大段底部留白，工具摘要保持 28 px 最小行高、上下 2 px 边距；失败保留文字标识，使用与其他命令一致的中性色。

服务端快照提供当前流式消息标识、活跃推理段和工具调用 ID，前端同步消费原有 SDK 事件。进行中的消息包含在快照中，刷新或进度更新不会把正在显示的内容移除。消息使用稳定标识，避免原生历史落盘后重建详情块；这些执行状态只存在于运行期，不写入 Pi 会话格式或额外配置。

## 编辑框上方的项目与模式

项目名称与运行模式放在编辑框左上方，作为同一 `composer-area` 内的上下文行，宽度随编辑框对齐，保留图标与下拉箭头。该行位于消息滚动容器之外，与编辑框一起固定在会话底部；欢迎页原有的重复项目 / 模式显示移除。长项目名在入口省略，在工作区菜单中换行显示，支持小屏和大字号。

项目下拉复用已有工作区选择与添加入口；选择其他项目进入该项目的新任务，已有会话的草稿继续保存。重复选择当前项目不清空草稿。运行模式仅保留输入框上方的菜单，移除正文标题右侧的重复入口；当前会话切换继续使用 Pi SDK，新任务先选择模式，发送时再创建会话。运行中禁用切换，点击当前已选模式只关闭菜单。

项目与模式按钮使用统一的 20 px 文字行框、16 px 前导图标及 12 px 箭头，文字上移 0.07 em 校正字体与图标的光学基线。图标、箭头和行高随整体字号同比缩放，保持两个按钮等高；样式限定在输入框上方的项目 / 模式区域。

输入框底部采用 DSH 的三个统计胶囊与向上展开浮层，复用 `Menu` 的定位、主题、外部点击关闭和焦点管理，以非模态 dialog 显示明细。Escape 关闭并返回触发器，Tab 关闭并继续遍历；同一时刻只显示一个浮层，窄屏限制在视口内。三个指标均以当前会话为范围，不混入子 agent 的独立上下文或计时。会话轮次沿用用户轮次，步数取模型回复数，工具调用单列；模型 / 工具总用时汇总原生历史的 durationMs，缺失时读取轨迹计时。每次响应记录首个文本 / 推理 / 工具参数增量延迟和解码时段，按有效样本求 TTFT 平均、输出 tokens / 解码秒数求 TPS，重载后保留，旧历史缺失则显示“未记录”。Token 取 SDK 累计值，缓存命中分母包含未缓存输入、缓存读取与缓存写入；无输入时显示未知。上下文总量 / 窗口沿用 SDK，拆分按当前系统提示词、活跃工具 schema 和可见消息的字符估算比例分摊，并标注为估算；压缩后 tokens 为 null 时隐藏图表并说明，累计 Token 不当作上下文占用。

## 会话列表更多菜单

CLI / Web 轮流共用同一 JSONL；外部客户端续写后可打开设置自动重载当前会话资源，或重启 Web 服务，当前不监听外部文件变化，也不支持同时写同一文件。重新加载时按事件顺序重建调用计数：`model_request` 记录实际观测到的调用，随后原生助手 / 摘要条目不重复计数；没有对应调用事件的原生回复按一次估算。任务边界和用户输入重置关联，避免将上一轮未完成调用错误关联到新一轮。TUI 的正文与上下文可正常读取，普通 custom 元数据不渲染为消息。Pi Desk 的权限 / 运行模式和 SSH 工具接入由宿主管理，不随原生文件自动注入其他客户端。

运行日志统一保存在原生 session JSONL：通过 SDK `appendCustomEntry("pi-desk-event", data)` 写入补充计时、任务边界、重试 / 压缩过程和子任务事件。原生条目的 ID、时间戳负责事件身份，助手计时以 `messageTimestamp` 关联，工具事件以 `toolCallId` 关联；不复制正文、参数、结果和 usage，压缩摘要继续读取原生条目。普通 custom 记录不进入模型上下文；响应计时在 SDK 持久化该回复前追加，按消息 fork 时随其祖先路径保留，后续回复的计时不会混入。API 和 SSE 沿用既有轨迹结构，数据源改为 SessionManager；不再读写独立 traces，也不备份或迁移旧 traces。新会话从首条用户消息开始沿用 SDK 的持久化规则，空白草稿仍由应用状态保存。

会话行默认显示相对更新时间；鼠标悬停或键盘聚焦时，右侧以三个点替换时间显示。菜单打开时入口保持可见，使用现有 DSH 圆角菜单、分隔线与图标。触屏无需悬停，入口常显且触控区域为 44 px。

菜单作用于该行对应的会话，打开菜单不切换当前对话。提供置顶 / 取消置顶、重命名、分叉会话、复制 Session ID、在文件夹显示、归档 / 恢复；复制的是 Pi Desk 会话 ID，在文件夹显示使用目标会话的实际工作目录。运行中的会话禁用分叉与归档，未保存历史的会话禁用分叉。置顶写入现有应用元数据，跨工作区集中在独立置顶区显示；取消置顶立即回到普通列表，两种分组均不重复展示。两区各按最近更新排列。归档记录默认隐藏，可在视图选项中显示全部或仅显示已归档，再通过对应会话菜单恢复。

重命名与顶部标题入口共用弹窗，支持 Enter 保存、取消及焦点恢复。分叉复用 Pi SDK 独立历史文件；打开目录复用工作区接口。方向键、Home / End、Enter、Escape、外部点击、滚动定位和视口边界沿用共享 Menu，不展示未实现的快捷键。

## 设置标签与行为

每次打开设置时自动重载当前会话资源；空闲会话立即应用，运行中的会话在任务结束后应用，保留消息历史和模型选择。没有当前会话时仍正常打开设置。资源页不提供手动重载按钮，agent 设置底部不重复提供插件管理按钮。

首项为“外观”，分为界面设置和代码设置两组：主题、语言、界面字体 / 字号，以及浅色 / 深色代码主题、行号、长行换行、代码字号。右侧与“agent设置”共用内容区域、分组与设置行样式，统一背景、留白、标题、说明和下拉框；移除外观页独立的灰底、卡片边框与字号覆盖。界面字号为 12–18 px，作用于全局文字；代码字号独立为 10–18 px。字体和代码偏好保存在浏览器本地，刷新后恢复；主题继续复用服务端偏好。

语言目前仅提供简体中文。代码配色沿用原 Pi Desk 的主题，`Code.tsx` 统一处理文件与 Git 差异，支持跨行高亮与 Windows CRLF；差异行号采用对应的源文件行号。超过 200,000 字符或 10,000 行时使用完整纯文本预览，保留字体、字号和换行设置，暂停行号与高亮以避免过多 DOM。

第二项为“agent设置”，直接显示“输入与会话设置”和“子 Agent 设置”。子 Agent 角色使用表单分别编辑名称、说明、模型和提示词，支持编辑内置 worker / scout / reviewer、新建和删除自定义角色；模型可选具体模型或继承父会话模型，保留未出现在表单中的工具权限和其他配置。新角色由名称生成文件名，不要求填写路径或 YAML。读取内置默认配置不创建文件，保存到用户 `~/.pi/agent/agents/*.md` 或项目 `.pi/agents/*.md`，项目同名定义优先，下次委派生效；删除覆盖文件后回退到同名用户定义或内置配置。scout / reviewer 保持只读。`subagent` 在插件管理中单独启停，默认启用，开关对所有会话及子 Agent 生效，运行任务结束后应用，极简模式始终不提供。保留发送按键、繁忙时行为、代码字体、快捷键、历史发现、模式说明。插件管理统一使用左侧设置导航入口。

子 Agent 会话不显示在左侧列表、搜索和置顶中。点击主会话的 `subagent` 调用或子任务条目，在右侧面板查看对应消息、工具执行和实时输出，主会话保持不变；并行子任务分别选择，嵌套子任务支持进入和返回上一级。小屏使用同一面板的对话框布局。新子任务保存父工具调用 ID，历史调用使用返回结果中的子会话 ID 关联；从旧子会话入口恢复时定位到主会话并打开子任务面板。

第三项为“模型管理”：Auth / OAuth 浏览器登录和 API Key 接入使用 Pi 认证接口，按提供商能力筛选。可用模型列表支持搜索、用于当前会话和设为默认；默认值写入全局 `settings.json`，新会话创建时记录该选择，已有会话保留原模型。

API 提供商选择框旁增加“新增提供商”，复用现有模型配置表单填写自定义 ID、API 地址、协议、密钥及首个模型；地址必填，密钥可稍后通过 API Key 入口配置。打开表单时滚动定位并聚焦 ID，取消不保存。保存后刷新原生模型目录并自动选中新提供商；服务端拒绝已配置或内置提供商的重名 ID，既有添加 / 编辑模型操作继续沿用原接口。

API 模型区支持提供商和模型配置的查询、新增、编辑、重命名、删除确认及搜索；内置 Auth 模型由 SDK 维护，退出认证沿用原入口。复用 `models.json`，编辑基本字段、地址、协议、密钥、上下文 / 输出上限、思考和图片能力；高级 JSON 保留 `headers`、`compat`、`thinkingLevelMap`、`inputLimits` 等原生字段，压缩参数写入 `settings.json` 的 `compaction.modelOverrides`。不展示任务费用。密钥留空保留原值，支持明确清除；已有请求头和密钥只返回占位符。重命名同步相关默认值和压缩覆盖，删除相关配置时清理默认值和压缩覆盖，保留历史会话与 `auth.json`。

后端复用随 SDK 分发的模型 schema 校验；模型和设置文件采用临时文件替换，第二次替换失败时恢复已替换文件。无效配置不覆盖原文件，保留未编辑字段，支持 Pi 的行注释与尾逗号。空闲会话再次发送前刷新模型配置；已删除或失去认证的模型必须先重新选择，运行中的任务保持当前请求。表单和列表使用现有 DSH 样式与自定义 Select，未增加应用文件、依赖或独立存储格式。

第四至第八项依次为“prompt管理、skills管理、mcp管理、插件管理、关于软件”，共八项。prompt / MCP / 插件管理复用现有资源接口，支持用户 / 项目作用域及相应编辑、删除确认与空闲会话重载；skills 管理展示列表、全局启用开关及删除按钮。MCP 密钥遮盖并保留占位符原值；插件管理包含插件源码、资源包和 Agent 定义。移除本地资源包使用 SDK 返回的安装路径，缺失目录时按配置根目录解析相对路径，并确认配置已移除。

插件管理复用 skills 的列表样式，收起时显示等高的名称与单行路径。点击源码或 Agent 定义，按需读取并展开完整路径与源码编辑；收起后保留当前草稿，切换文件或新建前确认未保存内容。资源包展开显示来源、安装路径与作用域。保留新建、保存、删除确认、安装 / 移除和会话重载，浏览详情不执行插件代码。

Skills 加载继续使用 SDK 的 `DefaultResourceLoader` 与原生包管理器：标准模式自动发现用户 Pi 配置目录的 `skills/`、`~/.agents/skills/`、工作目录的 `.pi/skills/`、向上至 Git 仓库根的 `.agents/skills/`（无仓库时至文件系统根），以及 settings / 资源包指定路径，沿用 SDK 的覆盖、去重和按需读取规则。极简模式保持 `noSkills`，不加载这些来源。设置页单独使用只读 Skill 列表，名称与单行简介作为原生 details / summary 的入口；过长名称与简介省略显示，空简介保留一行高度，收起列表项高度一致，展开显示绝对路径及完整原文；长内容在详情区滚动，正文按需请求，并在当前列表中缓存。移除作用域、创建、编辑及重载控件，原文按文本安全显示；列表右侧的启用开关和删除按钮独立于 summary，操作不会误展开详情。开关默认启用，使用既有应用状态的 `preferences.disabledSkills` 按名称保存全局停用名单，覆盖所有工作区、会话与子 agent。服务端用原生 `DefaultPackageManager.resolve()` 与 `loadSkills()` 获取启用的目录 / settings / 已安装资源包条目，不执行扩展或安装缺失包；详情仅允许读取当前发现的 skill，限制预览为 1 MiB，原资源接口不再接受 skill 文件操作。原生发现规则保持不变。运行时包装资源加载器的公开 `getSkills()`，在原生结果上过滤全局停用项与已不存在的文件；通过 SDK 的工具设置接口重建提示词，空闲会话立即更新，正在运行的任务保留本轮提示词快照，结束后新请求采用更新。保留历史消息，不中断任务或重启扩展；保存失败时恢复内存中的原停用名单。

删除仅允许操作当前原生发现列表中的准确文件，确认弹窗展示绝对路径，永久删除该技能文件；同名其他来源可按原生优先级重新出现在列表。取消不提交删除，失败保留弹窗并聚焦错误。移动端开关点击区与删除按钮至少为 44 px；沿用现有 DSH 开关、图标按钮、确认弹窗及主题，无新增依赖或应用文件。

“关于软件”分别读取根目录清单和实际安装的 Pi SDK 清单，显示软件版本与 SDK 版本，构建时自动同步。输入与会话设置及子 Agent 预设已移到外观下方的“agent设置”，不在关于软件页显示，不使用折叠容器。模型认证与资源管理沿用同一套 DSH 原语。

## 阶段 4 集成边界

定时任务复用同一个 Runtime 和 SDK，支持单次、每天、每周；按 Node 服务主机时区计算，在开始 SDK 工作前持久化运行槽位。同一任务不重入，不同任务可并行；手动运行不消耗未来计划。停机计划跳过，运行中任务恢复为暂停，避免自动重复文件或命令副作用。模型、模式和推理等级必须按配置执行，失效时明确报错，不自动降级。旧任务迁移后暂停，确认参数后启用。

SSH 工作区采用本机 Node.js + Pi SDK、远端 Go helper。Node 复用 OpenSSH 别名、ProxyJump / ProxyCommand、密钥与严格 known_hosts 校验，固定连接配置和已知主机摘要。每个工作区共享持久 SSH stdio 连接；模型请求、AgentSession、子 Agent 和 JSONL 在本机进程内执行，不采用 Pi CLI RPC，也不为每个 agent 启动进程。

Go helper / 二进制协议优先复用旧实现，独立 Go 模块不含 Wails。构建时提供 Linux / macOS x64、ARM64 的 CGO_ENABLED=0 产物，manifest 记录协议、构建身份、长度和 SHA-256；远端压缩上传到 ~/.pi/desk/remote-helper/1/<sha256>/helper，校验后复用，不安装语言运行时或下载 npm 依赖。握手校验 nonce、平台、版本与能力；根目录以 canonicalPath / device / inode 绑定，操作使用能力句柄。请求 / 响应 / 事件 / blob 复用原分帧协议，校验连接代次、输出序号、大小和 credit。取消传到进程组，断线拒绝未完成请求且不重放修改；协议资源限额由 Node 背压消化，worktree 根句柄在操作后引用计数释放。

SDK 的工作目录是本机 SSH anchor，逻辑项目 cwd 保留远端 POSIX 路径。read / edit / write / bash 复用 SDK 的工具格式与输出处理，底层经 Go helper 执行；find / grep / ls 适配原 helper 搜索。远端路径不得进入本机默认文件工具；本机已启用 Skill 及引用目录单独经 realpath 校验后读取。每轮追加远端 AGENTS.override.md / AGENTS.md，默认 Skills / 插件 / MCP / 模型配置均来自本机。MCP 不自动转为远端服务；任意 Shell、可信插件与 MCP 不是工作区文件沙箱。

子 Agent 继承工作区绑定和深度限制；远端 Git worktree、变更整合与 PTY 均使用同一 helper。定时任务也由本机 SDK 执行，模型参数失效时失败，不切到远端配置。右侧文件预览复用 Go 文件接口，限制在远端工作区根目录，本机应用不会接收远端路径。

迁移先保留原工作区 / 会话 ID、草稿、归档、置顶与父子关系，再只读复制旧远端 JSONL 和引用图片，不再导入独立 traces。使用历史专用子目录能力，不读取远端认证或扩展；检查 JSONL 分支引用、SHA-256、源文件稳定性和目标冲突后提交本机状态，失败不创建替代空会话。源路径与校验值保留在 remoteHistory，导入前状态另存备份；原远端数据和旧运行时不删除。旧 Wails 的本机 SSH JSONL 保留，通过一次性元数据迁移恢复入口。已导入历史离线可读，待发队列暂停，重连不补跑修改。

独立浏览器采用 Playwright Core 复用已安装 Chrome / Edge / Chromium，单独 profile，不连接用户现有浏览器。右侧文件栏默认显示「开始」页，通过入口卡片打开工作区文件或新建浏览器。文件和网页按需打开为可关闭标签，Agent 调用浏览器时定位对应网页；支持导航、查看页面、点击、输入和滚动；默认无头运行，设置 `PI_DESK_BROWSER_HEADLESS=0` 可显示原生窗口。Standard 模式工具 `desk_browser` 默认允许控制，可在插件管理中全局关闭；Minimal 和只读会话不加载。Agent 调用时自动展开浏览器面板，标签操作权限按会话隔离，Cookie 与登录状态共用同一 profile。工具接受 HTTP / HTTPS 和语义元素操作，不提供任意 JavaScript / Cookie 接口；坐标与键盘输入接口仅供用户面板使用。整个浏览器仅允许用户关闭。电脑桌面控制继续复用配置的 MCP 工具。

后台完成写入持久化未读；页面可见且正在查看该会话时确认已读。浏览器通知需用户主动授权，按完成事件去重，仅后台或其他会话提示；浏览器退出后不承诺系统通知。布局在浏览器按工作区记住右侧面板、文件路径 / 活动标签和显示方式，区块折叠与左右宽度沿用原偏好；不缓存文件正文、密钥或工具输出。

关于软件提供版本检查与诊断下载。版本检查仅在点击后访问项目 GitHub Releases，不自动安装；诊断用白名单导出环境、计数和状态，不含认证、路径、会话标题 / 正文或工具输出。发布资源只包含 Node / Web 产物、锁文件、许可和仍被复用的图标 / 扩展；升级步骤见 README。Windows 和 Linux 的生产构建、SDK / HTTP / PTY / 调度 / 独立浏览器检查已有本地证据；macOS CI 与真实电脑控制 MCP、系统通知授权仍分别记录为待验收。

## MCP 管理列表与详情页

MCP 与 skills 共用列表行、单行省略、启用开关和删除入口；提供“按 Pi 生效 / 用户 / 项目”范围，展示实际文件路径和项目覆盖标识。点击服务后，以独立详情内容替换列表，包含来源、作用域、名称、JSON 配置、保存和调试；返回时检查未保存更改。详情与调试结果切换时同步滚动和键盘焦点。新增、删除确认、调试失败、空列表及小屏使用同一套 DSH 组件。

服务配置发现、覆盖和校验复用锁定 Pi SDK 1.4 分发的 MCP 模块，不另写配置发现器：只读取 agentDir/mcp.json 与受信任 cwd/.pi/mcp.json，不向上扫描目录。读取不会创建缺失的 .pi；写入继续使用已有资源写入逻辑，保留无关顶层字段 / 服务和密钥占位，采用独立临时文件替换。单文件修改串行，编辑版本改变时拒绝旧详情覆盖。无效条目按 SDK 报错并跳过，Minimal 模式不加载 MCP。扩展动态注册服务继续由 SDK 与插件维护，不伪装成可编辑文件条目。

独立调试复用 SDK McpServerConnection、默认传输与原生 OAuth 存储，使用当前编辑定义，仅 initialize / tools/list，含分页工具与完整参数 schema；不执行业务函数、不保存未提交配置。普通环境变量 / 请求头解析与认证仍按 SDK 执行，配置回显遮盖密钥，失败 stderr 隐去解析出的环境 / 请求头值。整体 60 秒期限，完成或取消后关闭连接；SSH 工作区同样在本机调试 MCP，取消直接关闭本机调试连接，不经远端 helper。已有会话按 Pi 规则手动重载，运行中不强制改动。

## 文件链接与预览范围

对话和预览中的 Markdown 共用现有 markdown-it。局部解析原生 Windows / POSIX 路径、file URI、相对文件链接及行内文件名；代码块保持原文，链接与文件属性按 HTML 规则转义，禁用原始 HTML。预览内相对路径以当前文件所在目录为基准；消息以会话工作目录为基准。点击本地链接时自动打开右侧面板；HTTP / HTTPS 链接通过本机服务交给系统默认浏览器，限制协议并拒绝 URL 中的认证信息，使用独立参数而非 shell 字符串。

目录接口仍校验工作区和 canonical path，拒绝越界目录，不在目录列表中展示符号链接。独立的单文件预览请求允许显式选中的工作区外文件，只读并拒绝外部目录、设备和非普通文件。文本按 UTF-8 解码；图片只开放 PNG / JPEG / WebP / GIF，PDF 使用浏览器原生预览并在退出时释放 Blob URL；文件超过 2 MiB、编码或格式不支持时显示明确提示。Office 预览按用户决定暂不实现；不把二进制内容误显示为文本。布局仅持久化标签路径、活动标签、目录展开和显示方式，不缓存文件正文。

文件预览右上角复用分体「打开方式」菜单，显示已安装的文件管理器、VS Code 和 Cursor，单独记住默认文件应用。编辑器接收当前文件路径；Windows 文件管理器定位并选中文件，macOS 使用 Finder 显示文件，Linux 打开所在目录。沿用单文件预览的路径范围，服务端校验普通文件，不把文件路径交给 Shell；SSH 文件禁用本机打开入口。「显示目录树」在预览右侧展开浮层，自动展开父目录并标记当前文件，可切换文件、通过按钮或 Esc 收起，保留文件预览。
